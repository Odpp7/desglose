# Canciones de prueba

Esta carpeta **no se sube a git** (derechos de autor). Estructura:

```text
samples/
  cancion1/
    original.mp3
    stems/          # se llena con la IA o con multitracks
  cancion2/
  referencia/       # una secuencia de las que el encargado descarga hoy
```

Elegir 3 a 5 canciones: una de estudio, una en vivo, una con guitarra eléctrica protagonista y una en 6/8 o 3/4 si tocan alguna.
